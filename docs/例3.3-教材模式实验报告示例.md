# 例3.3 单服务台排队系统仿真实验报告

> 本报告由当前已完成的仿真数据生成。时间单位为 min；排队累计面积的单位为人·min。

## 1. 实验目标与模型

通过未来事件表 FEL 选择最早事件，观察 CLOCK 跳转、服务台与 FIFO 队列的状态变化，并用状态区间面积核算统计结果。

- 系统：单服务台、先进先出等待队列。
- 事件：顾客到达、服务完成、仿真终止。
- 同时事件：先完成服务，再处理到达；在 T 时刻完成允许的离开后立即终止，不启动下一位顾客服务。

## 2. 输入参数

- 终止时间 T：8.6 min
- T 内纳入的顾客：8 位。未到达的顾客不进入本次结果。

## 7. 独立校验与结果解释

- 等待时间双重校验：顾客等待和 9.9 = 状态区间面积 9.9（通过）。
- 时间守恒：忙时 7.7 + 空闲 0.9 = T 8.6（通过）。
- 人数守恒：进入 8 = 离开 5 + 排队 3 + 服务中 0（通过）。
- 仿真终止时服务台空闲，队列为 [C6, C7, C8]。终止后不再生成服务过程。

## 8. 实验结论

**总体状态。** 在 8.6 min 的观察窗口内，8 位顾客进入系统，5 位完成服务，终止时 3 位仍排队、0 位正在服务。服务台忙碌 7.7 min，利用率 89.53%；空闲 0.9 min。队列是否清空，应结合终止状态判断，不能只看利用率。

**拥堵峰值。** 最大排队人数为 3 人，首次出现在 7.2–8.6 min；该区间的矩形高度是 Q=3，宽度是 1.4 min。

**等待集中区间。** 7.2–8.6 min 的 Q=3，持续 1.4 min，贡献 4.2 人·min，占总等待面积的 42.42%。因此总等待并非由所有时段平均产生。

**形成机制。** C5 在 4.9–8.6 min 实际占用服务台 3.7 min；期间另有 3 位顾客到达，队列长度由 0 变为 3。单服务台忙碌时，新到达顾客只能等待，这些等待按事件间区间逐段累计。

**截尾影响。** 终止时仍排队的顾客已经累计 7.2 人·min，占总等待面积的 72.73%。只统计已完成服务的顾客，会遗漏这部分真实等待；他们未开始的服务时间不能计入有效服务时间。

**结论适用范围。** 以上是给定到达间隔、服务时间与有限终止时刻的一次确定性仿真结果；它说明本次轨迹的机制和累计口径，不代表随机系统的长期稳态表现。
