02 / EXPECTED VALUE

数学期望：平均水平

把每个环数按它出现的概率加权，得到长期重复试验的平均表现。

逐项实时计算

E(X)Expected Value / 数学期望
描述随机变量的长期平均水平。 是什么？

E(X) = Σ xᵢP(X=xᵢ)

环数越高、对应概率越大，对最终平均成绩的贡献就越大。它不是某一次射击的结果，而是大量重复试验后的“中心位置”。

03 / VARIANCE

方差：平均值周围的波动

同样的平均成绩，可能由很集中的分布产生，也可能由很分散的分布产生。

D(X) 衡量离散程度

方差的三个动作

3加权

D(X)Variance / 方差
衡量数据围绕平均值的离散程度。 的两种写法

D(X)=Σ[xᵢ−E(X)]²P(X=xᵢ)
D(X)=E(X²)−[E(X)]²

距离先平方，是为了消除正负号，并让偏离很远的成绩受到更明显的惩罚。

04 / STANDARD DEVIATION

标准差：回到“环”这个单位

方差的单位变成了“环²”，开平方后，标准差重新回到与原变量相同的单位。

σ(X) = √D(X)

σ(X)Standard Deviation / 标准差
方差的平方根，与原变量具有相同单位。 的意义

σ(X)=√D(X)

标准差可以理解为：成绩通常会偏离平均成绩多少环。数值越小，成绩越集中，发挥越稳定。

当不同对象的平均水平差异较大时，还可以用变异系数 CV=σ/E 比较相对波动。

关键发现乙的标准差更小，说明乙的成绩更加集中。
